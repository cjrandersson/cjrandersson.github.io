# Character Design Project — Portfolio Direction

Working notes for a dedicated 2D character-design project page in the portfolio.

## Goal

Create a project page that is clearly focused on **2D character design** and shows selected characters as designed objects rather than as a generic image gallery.

The page should feel structured, intentional and art-directed, with enough process material to show how each character is developed and understood from multiple viewpoints.

## Page structure

### 1. Opening / Hero
- One strong hero character or artwork.
- Minimal title and short introduction.
- Keep the opening visually clean and image-led.

### 2. Character overview
- Introduce the broader collection of characters.
- Avoid a conventional portfolio grid where every image has equal weight.
- Use varied scale and rhythm: large artwork, smaller studies, details and sketches.

### 3. Hero character case studies
Select approximately **2–4 key characters** for deeper presentation.

Each selected character can include:
- Final 2D artwork
- Silhouette studies
- Early sketches / iterations
- Shape and proportion exploration
- Expression studies
- Pose studies
- Colour variations where relevant
- Detail crops
- Front / side / back turnaround
- Notes on visual language, construction or design decisions

The remaining characters can appear as smaller studies rather than full case studies.

### 4. Presentation language
The page can borrow lightly from an archive, field guide or specimen catalogue without becoming lore-heavy.

Optional small labels could include things such as:
- SPECIMEN / CHARACTER ID
- FORM
- STUDY
- ITERATION
- TURNAROUND

These labels should remain subtle. The artwork is the primary content.

## Explore Character

For the strongest characters, add an optional **Explore Character** section after the 2D case study.

Possible assets:
- High-resolution character sheet
- Turnaround sheet
- PDF character sheet
- Downloadable image package
- 3D interpretation where one exists

If a 3D version exists, consider embedding a lightweight web viewer so the visitor can rotate and inspect the character directly in the portfolio.

Suggested interaction:

**VIEW 3D**
- Rotate
- Inspect
- Fullscreen
- Optional `Download .GLB`

3D should be treated as a bonus layer rather than replacing the 2D character-design focus.

## Download strategy

Do **not** make every character downloadable.

Reserve downloadable material for a small number of highly developed hero characters. This makes the downloadable assets feel curated and prevents the page from becoming an asset repository.

A useful hierarchy:

1. **Hero characters** — full case study + turnaround + optional downloadable/interactive material
2. **Supporting characters** — final artwork + selected process/studies
3. **Experiments** — smaller visual studies, sketches and exploratory forms

## Visual rhythm

Prefer an artbook-like sequence over a uniform grid:

`large final artwork → sketches → details → turnaround → process → next character`

Allow generous negative space and alternate between full-width imagery and smaller technical/study layouts.

## Longer-term possibility

The character project can later become a bridge into a larger fictional world or game project. Characters, creatures, objects and environmental studies could gradually establish a coherent universe without requiring explicit lore at this stage.

The immediate priority, however, is to make the page work first and foremost as a strong **2D character-design portfolio project**.
